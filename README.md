# RB Solutions — Construction & Renovation Website

> Modern B2B landing page and web application prototype for corporate solutions, presenting the service lines and delivered projects of a construction and renovation company.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Construction & renovation (B2B/B2C)

Modern B2B landing page and web application prototype for corporate solutions, presenting the service lines and delivered projects of a construction and renovation company.

**Highlights**

- Service lines for residential, commercial and industrial works
- Portfolio of delivered projects with location and scope
- Lead capture and quote request flow

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
